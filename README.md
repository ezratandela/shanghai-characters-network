# Shanghai Characters Network Visualization

This project visualizes character relationships from a narrative set in Shanghai using an interactive D3.js network graph.

## Features

- Interactive force-directed graph of character relationships
- Color-coded nodes based on character gender
- Node sizes reflect character importance in the network
- Detailed character information panel
- Search functionality to find specific characters
- Zoom and pan navigation

## Data Structure

The visualization uses a JSON data structure containing:
- **Nodes**: Characters with attributes (name, gender, occupation, etc.)
- **Links**: Relationships between characters

## Technologies Used

- D3.js (v7) for data visualization
- HTML/CSS/JavaScript
- Force-directed graph layout
